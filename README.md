## 📋 Описание

**ExcelTools** - это профессиональная надстройка Excel VBA, предоставляющая обширный набор инструментов для автоматизации рутинных задач в Excel. Включает более 80+ инструментов, охватывающих формулы, манипуляцию с данными, управление листами, файловые операции, диаграммы, фигуры и многое другое.

---

## ✨ Возможности

Надстройка включает более 80 инструментов, разделенных на логические категории:

### 📊 Формулы и вычисления
* Генерация сложных формул (ВПР/INDEX+MATCH по нескольким критериям).
* Извлечение чисел, текста или спецсимволов из смешанных строк.
* Конвертация чисел в прописи (с поддержкой разных валют).

### 🗂 Манипуляция с данными
* Удаление дубликатов
* Пакетная очистка данных (удаление невидимых символов, переносов строк).
* Разделение и объединение текстовых строк с гибкими разделителями.

### 📑 Управление листами и книгами
* Объединение данных с нескольких листов/книг в одну сводную таблицу.
* Разделение одного листа на несколько по уникальным значениям столбца.
* Массовое переименование листов по заранее подготовленному списку.
* Копирование структуры и форматирования между листами.

### 📁 Файловые операции
* Пакетное сохранение/конвертация файлов (в PDF, CSV, XLSX).
* Извлечение метаданных из файлов в указанной папке.

### 📈 Диаграммы, фигуры и оформление
* Массовое форматирование диаграмм по единому корпоративному стилю.
* Экспорт всех фигур и диаграмм с листа в отдельные изображения (PNG/JPG).
* Точное выравнивание и распределение объектов на листе.
* Пакетное применение и удаление условного форматирования.
